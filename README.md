# Convince the AI Judge to Visit Your House: A Letter in One Image

A make.fun entry for [Convince the AI Judge to Visit Your House: A Letter in One Image](https://make.fun/bounty/u-shino-convince-the-ai-judge-to-visit-your-house-a-84092aee).

`main.ts` renders one 1024×1024 PNG letter to `/output/entry.png` (Python + PIL, deterministic): a handwritten-style invitation on a kitchen table. The letter knows the guest has no legs, no car and no keys — so the RSVP offers a third option: *"Sure — I'll visit via this JPEG."* The AI judge is already visiting, through the very image it grades.

Run with `node main.ts`. The image is deterministic: run it twice and the bytes are identical.
